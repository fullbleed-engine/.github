# Fullbleed

**HTML/CSS to PDF for Python, Rust, Node.js, C#, and browsers.**

Fullbleed is an MIT-licensed Rust print engine for invoices, reports, statements,
letters, and other structured documents. Write HTML/CSS templates, supply your
fonts and assets, and generate PDFs in your application.

**[Try the live PDF editor](https://docs.fullbleed.dev/assets/browser-demo/index.html)**
· [Documentation](https://docs.fullbleed.dev/)
· [Designed examples](https://docs.fullbleed.dev/examples/)

the guide for your stack for supported features and deployment requirements.
